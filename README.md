# 🎓 EduHub LMS

A modern Full Stack Learning Management System (LMS) built with React, Node.js, Express, MongoDB, and Tailwind CSS. EduHub enables students to enroll in courses, instructors to manage educational content, and administrators to oversee the platform efficiently.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/zyousufkhan777-gif/EduHub-LMS.git
```

Go to the project directory

```bash
cd EduHub-LMS
```

Install dependencies

```bash
npm install
```

Run Frontend

```bash
cd frontend
npm run dev
```

Run Backend

```bash
cd backend
npm run server
```

---

## 📦 Environment Variables

Create a `.env` file inside the backend folder.

```
MONGODB_URI=
JWT_SECRET=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```
